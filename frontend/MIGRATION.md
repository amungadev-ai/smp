M08A adds an authenticated API-driven Engine page at `/engine`, separate from the existing local demo resources. The typed client matches the uploaded Go M01 wire types. Go REST is same-origin `/api/v1`; Vite development proxies to `127.0.0.1:8080`. Login tokens are scoped to `sessionStorage`; authenticated container log streams use `fetch` with an Authorization header, never URL tokens. New engine deployment, job history, release listing and rollback controls use real API requests (or mock when server reports mock mode). Other native modules remain local simulations until explicitly migrated.
